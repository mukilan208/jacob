# jacob

**Pyro Prestige** — a premium pyrotechnics display planner web app. Curated catalog of high-budget display shells, cake assortments, firecrackers & salutes, and special effects with visual impact ratings, safety specs (NFPA 1123), tier pricing, and an interactive budget planner.

Built with Next.js 16 (App Router), TypeScript, Tailwind CSS 4 and shadcn/ui. Fully responsive for mobile and desktop.

## Getting started

```bash
bun install
bun run dev
```

Open http://localhost:3000 to view the app.

## Features

- **Premium catalog** — 24 professional products across 4 categories and 3 tiers (Signature / Flagship / Elite), each with impact rating, budget range, technical specs and safety notes.
- **Budget planner** — set budget, duration and program priority to get category allocation, tier strategy and a suggested build.
- **Safety & compliance** — NFPA 1123 minimum site radii by caliber and a licensing checklist.

## Tech stack

- Next.js 16 · TypeScript 5 · Tailwind CSS 4 · shadcn/ui · Prisma (SQLite)
